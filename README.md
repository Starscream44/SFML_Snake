# Snake — C++ / SFML

A classic Snake game written in **C++** using **SFML**.  
Collect apples, grow longer, earn points, and try to beat the high score.

▶️ Gameplay Video
https://youtu.be/YVuXbOZJDj8

## Features
- Grid-based movement
- Apple spawning system
- Score tracking
- High score table
- Collision with walls ends the game
- Clean modular architecture (Game / Snake / Apple / Walls / UI)
